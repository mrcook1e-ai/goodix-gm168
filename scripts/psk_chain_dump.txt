========================================================================
PSK STORAGE FORMAT ON MCU
========================================================================

MCU stores two TLV blobs concatenated:

  [TLV 0xBB010002] = DPAPI-sealed blob   (CryptProtectData output)
  [TLV 0xBB010003] = WhiteBox AES blob   (AES-128-CBC with "123GOODIX" key)

Both blobs contain the same 32-byte raw PSK, just differently protected.
The DPAPI blob is the authoritative one on Windows (unsealed by CryptUnprotectData).
The WB blob is the fallback / cross-check, decryptable offline.


========================================================================
EXTRACTION PATHS (no Windows / no SGX required)
========================================================================

PATH 1 — WhiteBox decrypt offline (pure Python, no Windows needed):
  1. Read MCU blob via PresetPskReadG USB sequence (0xE4 command)
  2. Find TLV 0xBB010003 blob
  3. Derive WB key:
       key = HMAC-SHA256(H0_init="SHA256_standard_IV", msg="123GOODIX")
       (standard SHA-256 IV = 6a09e667 bb67ae85 3c6ef372 a54ff53a ...)
  4. AES-128-CBC decrypt with that key → 32-byte PSK

PATH 2 — DPAPI unseal on same laptop (Windows, same machine):
  1. Read MCU blob → extract TLV 0xBB010002
  2. CryptUnprotectData(blob) → 32-byte PSK
  3. Works without any key if logged in as same user

PATH 3 — Frida hook (easiest, no RE of format needed):
  - Hook CryptUnprotectData return in WUDFHost.exe / Wbdi.dll
  - Or hook PresetPskPskSet (sub_1800a45b8) arg2 at entry = plaintext PSK
  - Or hook sub_18003836c (GeneratePsk) return = raw PSK before encryption

PATH 4 — x64dbg breakpoint:

RECOMMENDED: PATH 1 (offline WB decrypt) for Linux/libfprint integration.
